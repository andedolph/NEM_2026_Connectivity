### 1. Introduction

MQTT tooling in TwinCAT is particularly simple and comprehensive. In this lab, we will demonstrate basic usage of the MQTT client libraries to publish and subscribe to a web-hosted broker. You will also gain exposure to JSON handling and the use of the `ANY` type for writing generic, reusable functions.

<a id="dependencies"></a>

### 2. Dependencies

This lab uses TwinCAT 3.1 and the TF6701 IoT Communication library. Please make sure to install the TF6701 package. We will also be using the [*MQTT Explorer*](https://mqtt-explorer.com/) client tool for testing. If you already have a favorite MQTT client interface, feel free to use that as well.
